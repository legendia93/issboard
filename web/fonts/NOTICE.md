# Font pihak ketiga

`ndot.ttf` adalah **Pixelify Sans**, dirilis di bawah
[SIL Open Font License 1.1](https://openfontlicense.org/) — boleh dipaketkan
ulang dan didistribusikan bersama proyek ini.

Di-self-host (bukan diambil dari Google Fonts saat runtime) karena issboard
menyajikan `Content-Security-Policy: default-src 'self'` dan harus tetap
berfungsi di host yang tidak punya akses internet.

Font lain memakai stack sistem — tidak ada aset eksternal lain di proyek ini.
